### 입력 형식 프로필 (2026-10-03)
- **Current value/logic**: 헤더로 형식 감지(`detectOrderFormat`): 쿠팡 내보내기 / 외부 주문 도구(`날짜, 주문번호, 상품명, 수량, 금액, 배송비, 상태`). 외부 도구는 날짜 보정(`normalizeDateTime`), 임시 상품번호(`syntheticProductNo`, 접두어 99999 + 24자 이상), 금액(줄 합계) / 수량, 상태 별칭(`STATUS_ALIASES`, 주문취소 -> 취소완료), 배송비 파싱. 모르는 상태값은 `unknownStatuses`로 돌려 사용자가 짝짓게 함(쿠팡 형식 포함)
- **Implementation**: `src/lib/csv.ts`, 겹침 처리 `src/lib/importPlan.ts`(`planImport`: 외부 도구 형식은 자세한 주문 건너뛰기, 건너뛴 주문에는 배송비만 합침 `shippingUpdates`)
- **Related files**: `tests/unit/tool-format.test.ts`, `tests/oracle-tool.test.ts`(변환 결과를 쿠팡 형식으로 직렬화해 oracle과 비교), `tests/fixtures/orders_tool_fixture.csv`(가짜 데이터)
- **Rationale**: 외부 도구 파일은 쿠팡 내보내기보다 정보가 적고 반품 구분이 부정확해(실제 파일에서 배송완료 7행이 쿠팡 쪽에서는 반품완료) 겹치는 주문은 쿠팡 데이터를 우선. 임시 번호가 모든 행에서 고유해 중복 제거가 자연히 적용되지 않음
