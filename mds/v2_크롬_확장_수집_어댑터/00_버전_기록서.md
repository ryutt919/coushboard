- **버전**: v2 (폴더 mds/v2_크롬_확장_수집_어댑터)

## 개요
- 웹앱(v1)과 별개로 서버 저장 없이 `chrome.storage.local` 에만 저장하는 Chrome 확장 계열. 이번 버전은 쿠팡 내부 주문 API를 읽는 수집 어댑터 구현

## 직전 버전과 달라진 점
- v1은 CSV 업로드와 Supabase 저장. v2는 쿠팡 화면에서 직접 수집하고 브라우저 안에만 저장. v1 코드는 건드리지 않았고 확장은 `coupang-ledger-ext/` 에 독립

## 방법론
- DOM 클릭 대신 내부 JSON API를 같은 오리진으로 호출. 연도는 칩에서 읽고, 연도 안에서만 `hasNext` 를 따라간다
- 상태 대응은 사용자 CSV와 줄 수, 상태별 개수, 주문 수까지 대조해 확정

## 입력, 코드, 산출물
- 입력: 인수인계서 HANDOFF v2(조사 세션 결과), `coupang-ledger-ext.zip`, 사용자 CSV(대조용, 저장소 제외)
- 코드: `coupang-ledger-ext/lib/adapter.js`(신규), `lib/collect.js`(기본 간격 2.2~3.5초), `test/adapter.test.mjs`(신규)
