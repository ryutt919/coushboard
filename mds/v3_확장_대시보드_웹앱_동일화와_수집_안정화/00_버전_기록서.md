# 버전 기록서: v3 확장 대시보드 웹앱 동일화와 수집 안정화

## Task Metadata
- **Created/updated at**: 2026-10-05 15:50:00 KST
- **Model used**: `claude-sonnet-5-5`
- **User requirements**: 확장 대시보드를 웹앱과 기능이 완전히 같게 하고, 수집 중 팝업을 닫아도 계속되며 다시 시작해도 이중 수집되지 않게 개선하고 E2E까지 완료한다
- **버전**: v3 (폴더 mds/v3_확장_대시보드_웹앱_동일화와_수집_안정화)

## 개요
- v2의 확장(수집 어댑터)을 이어, 대시보드를 웹앱 코드 그대로 재사용하고 수집을 팝업과 무관하게 안정적으로 만든 버전

## 직전 버전과 달라진 점
- v2: 별도 JS 대시보드(웹앱과 기능이 다름), 수집 진행이 팝업 메모리에 있음, 수집이 겹쳐 시작되면 어댑터 전역 상태가 꼬임, 행은 끝에 한 번 저장
- v3: 대시보드는 웹앱 코드의 확장 빌드(저장소만 chrome.storage.local), 수집 상태를 저장소에 두고 한 번에 하나, 페이지마다 저장, 이어서 수집, 행 모양을 웹앱 OrderRow로 통일

## 방법론
- 웹앱 `Backend` 인터페이스에 `ChromeBackend` 를 추가해 같은 화면 코드가 확장에서 돌게 한다. 웹앱의 E2E 스펙을 `E2E_MODE=extension` 으로 확장에 그대로 실행해 기능 동일성을 확인한다
- 수집은 쿠팡 탭의 콘텐츠 스크립트가 돌리고, 상태와 체크포인트를 저장소에 남긴다. 저장은 background 의 한 줄 대기열

## 입력, 코드, 산출물
- 입력: 사용자 CSV(동일성 비교용, 저장소 제외), 합성 쿠팡 응답(수집 E2E)
- 코드: `src/lib/chromeBackend.ts`, `src/extension/`, `vite.extension.config.ts`, `extension.html`, `popup.html`, `src/state/AppState.tsx`, `src/components/Layout.tsx`(확장 분기), `coupang-ledger-ext/{background.js,content/collector.js,lib/*.js,manifest.json}`
- 테스트: `tests/e2e/fixtures.ts`, `tests/e2e-ext/collect.spec.ts`, `tests/unit/chromeBackend.test.ts`, `coupang-ledger-ext/test/*.test.mjs`, `playwright.extension.config.ts`
- 산출물: `coupang-ledger-ext/app/`(빌드 결과, 커밋하지 않음)
