## 7. 한계와 Future work
- 완료 알림: 적용 범위는 이 Windows PC의 로컬 Codex와 Claude 호스트다. 기존 Codex 세션에는 이전 설정이 로드됐을 수 있으므로 새 대화부터 사용하며, 필요하면 실행 중인 작업을 마친 뒤 VS Code 창을 다시 로드한다. 다른 컴퓨터나 SSH 호스트에는 별도 설정이 필요하다.
- 확장: 쿠팡 비공개 내부 API라 구조가 바뀌면 깨지며 이용약관 저촉 여부는 확인하지 못함. 가장 오래된 연도 끝의 `hasNext`, `size` 확대 가능 여부, 결제 직후(ACCEPT/INSTRUCT) 줄의 CSV 상태는 미확인. 수집 도중 오류가 나면 그때까지 읽은 행은 저장되지 않음
- 규칙 충돌 감지는 "그 키워드가 없다면 서로 다른 카테고리로 갈 때" 기준의 단순 휴리스틱
- 설정 가져오기는 여러 요청으로 나뉘어 완전한 원자성은 없음
- 영수증 포함 실데이터 기대값은 영수증 CSV 확보 후 `verify:real --receipts` 로 확인 필요
- 변이 검사(RLS를 끄고 H8이 실패하는지 확인)는 운영 DB에서 DDL이 필요해 하지 않음. 로컬 스택이나 CI에서 수행 권장
- Supabase Auth의 유출 비밀번호 보호(HaveIBeenPwned)는 무료 플랜에서 꺼져 있음(어드바이저 경고 1건)
- Vercel 프로젝트에 Supabase 연동이 붙인 환경변수(`SUPABASE_SERVICE_ROLE_KEY`, `POSTGRES_*` 등)가 있음. 클라이언트 번들에는 `VITE_` 변수만 들어가므로 노출되지 않지만, 작업 지시(관리자 키를 Vercel에도 두지 않기)에 따라 사용자가 삭제하는 것을 권장
- 테스트용 Auth 사용자(`rls-*`, `coushboard-e2e-*@example.com`)가 남아 있음. Authentication 화면에서 삭제 가능
