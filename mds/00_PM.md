- 자료: handoff/(작업 지시, oracle, 픽스처, 마이그레이션), ref/(디자인 시안 3개), data/(사용자 실데이터, 저장소에는 올리지 않음)
- 환경: Node 24, Vite, React, TypeScript, Supabase 프로젝트 `kjfmwbwnpdhmdtadiyrs`(서울), GitHub `ryutt919/coushboard`(비공개)
