- **User requirements**: 다른 도구로 내려받은 주문내역 CSV(`날짜, 주문번호, 상품명, 수량, 금액, 배송비, 상태`)도 업로드할 수 있게 한다. 결정: 겹치는 주문은 건너뛰기, 배송비 컬럼과 별도 합계 표시, 주문취소 -> 취소완료, 이 형식에는 중복 제거 미적용.

## 입력 파일 분석 (사용자 파일, 저장소에는 넣지 않음)
- 228행, 주문 133개, 2025-09-30 ~ 2026-09-30. 사용자가 일부 수정한 헤더(`주문일시`, `판매가`, 빈 ` 상품번호`)였고 원본은 `날짜, 주문번호, 상품명, 수량, 금액, 배송비, 상태`
- 쿠팡 형식과 다른 점: 날짜만 있음, 상품번호 없음, `금액`이 줄 합계(수량 2인 4행에서 기존 파일의 금액과 일치), 상태가 `배송완료`와 `주문취소` 두 가지, 옵션 없는 상품명, 배송비 3행(9,000원 2건과 3,000원 1건)
- 기존 `data/` 파일과 비교: 133개 주문이 모두 겹침. `주문취소`는 기존의 취소완료 8행과 반품완료 50행에 섞여 있고, 새 파일에서 `배송완료`인 7행이 기존에서는 반품완료. 즉 기존 쿠팡 내보내기가 더 정확함

## 구현
- **형식 감지와 변환**(`src/lib/csv.ts`): 날짜 보정, 임시 상품번호(행마다 고유), 금액 / 수량(나누어떨어지지 않으면 수량 1로 두고 안내), 상태 별칭, 배송비 파싱. 쿠팡 형식 경로는 그대로
- **모르는 상태값**: 쿠팡 형식 포함 줄마다 오류로 막지 않고 보류, 업로드 화면에서 짝지으면 올림
- **겹침 처리**(`src/lib/importPlan.ts`): 외부 도구 형식은 실제 상품번호가 있는 주문을 건너뜀(기본), 덮어쓰기 선택 가능. 건너뛴 주문에는 배송비만 주문 단위로 합쳐 넣음. 같은 도구로 올린 주문은 새 내용으로 교체
- **배송비 저장**: `order_items.shipping_fee`(마이그레이션 `20261003000000_shipping_fee.sql`, `replace_orders` 재정의). 개요 총 지출 카드에 "배송비 별도 N원", 업로드 결과에도 표시. 총 지출에는 더하지 않음
- **중복 제거**: 임시 번호가 행마다 고유해 이 형식에는 적용되지 않음(테스트로 확인)
- **업로드 화면**: 형식 배지, 변환 안내, 상태 짝짓기, 겹침 미리보기와 선택, 올리기 확인. 올릴 것이 없으면 이력도 만들지 않고 안내
