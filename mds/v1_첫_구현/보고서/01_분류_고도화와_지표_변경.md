# 분류 고도화와 지표 변경 (v1)

## Task Metadata
- **Created/updated at**: 2026-10-03 18:10:00 KST
- **Model used**: `claude-sonnet-5-5`
- **User requirements**: 카테고리 정리에서 반품, 취소 제외. 사용자가 PDF로 준 직접 분류를 참고해 자동 분류 고도화. 헷갈리는 단어는 직접 확인하고 지정하는 섹션으로 교체. 카테고리 종류 사용자 추가. 결제 내역 정렬. 가장 큰 구매와 상품당 평균을 1개당 가격 기준으로.
- **버전**: v1 (폴더 mds/v1_첫_구현)

## 핵심 결과
- 실데이터 받은 상품 미분류 **87건 -> 0건**, 사용자가 직접 지정한 13개 유형이 모두 같은 카테고리로 자동 분류
- 기존에 분류되던 품목 중 바뀐 것은 5개이고 모두 개선(냉동밥보관용기 식품 -> 생활용품, 러그와 카페트 건강 -> 생활용품, 테이프 커터기와 오토바이 방수커버 운동 -> 생활용품)

## 입력 (PDF) 해석
- `쿠팡 지출 기록.pdf`는 카테고리 정리 화면 캡처이고, 사용자가 직접 지정한 13개 품목과 규칙 충돌 20개가 담겨 있음
- 직접 지정: 파인애플 스틱, 올리고당, 김, 또띠아, 손질 배추, 절단무(식품), 크레아틴(운동), 토퍼, 방수커버, 에그밥솥, 서랍장, 반팔 티셔츠(생활), 스마트워치(디지털)
- 이 외 미분류 품목은 실데이터에서 직접 추출해 일반 어휘 기준으로 키워드를 설계

## 변경
- 확장 키워드 `src/data/category-rules-extra.json` (기본 규칙은 handoff 골든 테스트 때문에 수정하지 않음, 병합은 `stored.ts`)
- 키워드 보정: `스텐` 이 `익스텐션` 에 걸려 건강·의료 캡슐이 생활용품이 되던 것을 `스텐(?!션)` 으로 수정, 수영복 `반바지` 는 제거
- 카테고리 정리: 받은 상품만, "직접 확인할 상품" 섹션, 카테고리 종류 추가와 삭제, 모든 선택 UI에 "+ 새 카테고리"
- 대시보드: 결제 내역 정렬(거래일시, 1개당 가격, 금액), 가장 큰 구매와 상품당 평균을 1개당 가격 기준으로(`src/lib/stats.ts`)

## 검증
- `npx vitest run tests/unit tests/golden.test.ts tests/oracle.test.ts tests/property.test.ts`: 74개 통과(확장 분류 유형, 병합 규칙, 카테고리 추가와 삭제, 지표)
- `verify:real`: 5개 기간 x 3개 상태 불일치 0건(기본 규칙 기준 oracle 비교, 변동 없음)
- `COUPANG_REAL_CSV=... privacy-scan`: 실데이터 상품명 503종 대조 발견 0건
- E2E(Playwright) 예시 화면 6개, 픽스처 시나리오 4개 통과: 카테고리 정리 건수가 "받은 상품만" 건수와 같음, 카테고리 추가와 삭제와 중복 거부, 직접 확인 섹션에서 지정, 정렬 방향과 aria-sort, 가장 큰 구매 = 1개당 가격 정렬 맨 위
- 정렬 E2E에서 접근성 위반 발견: 카테고리를 고르면 나머지 행을 투명도 0.5로 흐리게 해 색 대비가 부족. 막대 색만 흐리게 바꿔 해결

## 세부 내역 개선 (추가 요청)
- 검색어가 있고 일치하는 품목이 2개 이상이면 "'검색어' 검색 결과 전체" 항목을 맨 위에 두고 기본 선택. 합계는 그 단어가 들어간 모든 구매(한 번만 산 품목 포함)이며, 아래 개별 품목을 누르면 그 품목만 표시. 검색어를 바꾸면 다시 전체 선택
- 그래프는 위쪽 기간과 별개의 기간(날짜 입력, 바로 선택)과 단위(자동, 월별, 연도별)를 가짐. 기존에는 전체 기간(18개월 초과)에서 연도별만 나왔음
- "최근 12개월"은 달의 1일부터 시작해 정확히 12개 막대가 나오게 함(처음엔 달 중간부터 시작해 13개가 나오는 것을 E2E로 발견해 수정)
- 막대가 18개를 넘으면 값 레이블 대신 툴팁으로 표시해 겹침을 막음
- 검증: E2E 2개 추가(검색 전체와 개별 선택 전환, 그래프 기간과 단위 전환 및 막대 개수), 단위 전환 버튼 줄바꿈 레이아웃 문제를 스크린샷으로 발견해 수정

## 판단과 한계
- "상품당 평균"은 총 지출 / 총 수량으로 해석(수량을 반영한 1개당 평균). 단순 행 평균을 원하면 변경 가능
- 에그밥솥은 이제 자동으로 생활용품이 되므로, 저장 유지 E2E는 자동 분류와 다른 디지털·전자로 바꾸는 시나리오로 조정
- 키워드는 일반 어휘 중심이라 드문 상품은 여전히 미분류가 될 수 있음(카테고리 정리에서 직접 지정)
