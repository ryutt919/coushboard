## 배포 중 발견한 문제와 수정
- 로그인 버튼 비활성: Vercel CLI가 `VITE_SUPABASE_ANON_KEY` 를 자격 증명으로 보고 기본 저장을 거부해 키가 빠졌음. `--type config` 로 추가 후 재배포
- CSP 폰트 차단: 작은 폰트 파일이 data: URI로 인라인되어 `font-src 'self'` 에 막힘. `vite.config.ts` 의 `build.assetsInlineLimit: 0` 으로 수정, CSP는 유지

## 구현 판단과 handoff와 다른 점
- 인증: 이메일+비밀번호, 가입 버튼 있음, 가입 차단 안 함 (사용자 지시)
- 파이썬 `round` 동률 처리(짝수 쪽)를 `round2` 로 재현
- CI 워크플로는 토큰에 workflow 권한이 없어 `ci/` 에 둠
- Docker와 Supabase CLI가 없어 로컬 스택 대신 원격 프로젝트에서 H8, H9를 실행(테스트 사용자 가입 후 데이터 삭제). RLS 변이 검사는 DDL이 필요해 하지 않음
